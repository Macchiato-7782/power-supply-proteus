# 电源仿真：Buck / Boost / LM317

三个电源拓扑的 Proteus 原理图仿真：

| 文件 | 拓扑 | 说明 |
| --- | --- | --- |
| `proteus/buck.pdsprj` | Buck 降压 | 开关管、电感、续流二极管、输出电容；观察占空比与输出电压 |
| `proteus/boost.pdsprj` | Boost 升压 | 电感储能、开关管、输出二极管；观察升压比与纹波 |
| `proteus/lm317.pdsprj` | LM317 线性稳压 | 可调三端稳压器，电阻分压设定输出电压 |

## 使用

1. 用 Proteus 8.13+ 打开对应 `.pdsprj`。
2. 运行仿真，用示波器/探针观察开关节点、电感电流和输出纹波。
3. 修改占空比、电感、电容、负载，对比稳态和瞬态响应。

## 说明

- 这三个是模拟/开关电源原理仿真，不含单片机固件。
- 仿真模型是理想化器件，实际设计还需要考虑 MOSFET 驱动、死区、二极管反向恢复、ESR、PCB 布局和散热。
- 元件参数以原理图内标注为准；不同 Proteus 版本的模型参数可能略有差异。
